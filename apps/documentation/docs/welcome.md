# Welcome

Welcome to the Healthy-Relationship project documentation.

## Project Structure

```
apps/
├── backend/          # NestJS 11 API + Worker
├── frontend/
│   ├── admin-web/    # Next.js 15 Admin Panel
│   └── packages/     # Shared packages
├── mobile/
│   └── mobile-app/   # Expo / React Native
└── documentation/    # This documentation site
```

## Apps

- **Backend**: NestJS 11 with Prisma, Redis, BullMQ, OpenTelemetry
- **Mobile App**: Expo / React Native
- **Admin Panel**: Next.js 15 with Tailwind CSS
- **Documentation**: Docusaurus 3
