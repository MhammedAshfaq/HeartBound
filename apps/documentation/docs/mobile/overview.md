# Mobile App Overview

Expo / React Native mobile application located at `apps/mobile/`.

## Tech Stack

- **Framework:** Expo SDK 54 + React Native 0.81
- **Routing:** Expo Router (file-based)
- **UI:** gluestack-ui + nativewind (Tailwind CSS)
- **State:** React Contexts
- **i18n:** i18next + expo-localization
- **API:** OpenAPI-generated SDK via ApiContext
- **Language:** TypeScript
