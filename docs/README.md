# 📱 Relationship Strengthener App

## 📌 Overview
This application is designed to help users improve their relationships through small, consistent daily actions. The app provides personalized suggestions and reminders to encourage meaningful interactions between partners.

## 🛠️ Prerequisites

- Node.js >= 18
- npm or yarn
- Expo CLI

Install Expo:

```bash
npm install -g expo-cli
```

---

## ▶️ Running the App

```bash
npx expo start
```

This starts the Expo development server. Once running:

- **Scan QR code** with Expo Go (Android/iOS)
- Press **`a`** → Android emulator
- Press **`i`** → iOS simulator
- Press **`w`** → web browser
